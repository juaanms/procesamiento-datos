# Taller: Introducción al Lenguaje de Programación Python

## Descripción del Taller
Taller introductorio al lenguaje de programación Python,
indispensable en el mundo de la Ciencia de Datos.

## Estructura del Taller

| Sección | Tema | Porcentaje |
|---------|------|------------|
| 01 | Cadenas | 10% |
| 02 | Tuplas | 10% |
| 03 | Listas | 10% |
| 04 | Conjuntos | 10% |
| 05 | Diccionarios | 10% |
| 06 | Condiciones | 10% |
| 07 | Bucles | 10% |
| 08 | Funciones | 10% |
| 09 | Clases | 10% |
| 10 | Bono | 5% |

## Metodología de Trabajo
- Cada cuaderno incluye membrete de identificación.
- Documentación explícita de cada instrucción.
- Conclusiones al final de cada sección.
